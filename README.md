## About me

I build the checks that make data trustworthy before anyone analyses it.

Most of my work sits upstream of the insight: cleaning, validating and structuring data so that what comes out the other end can actually be relied on. I write automated tools in Python and SQL that flag missing values, inconsistencies and duplicates before they reach the analysis, and I document the procedures so quality control does not depend on one person remembering how it works.

Graduate of the Applied Data Science program at La Cite Collegiale, based in the Montreal region, working in both French and English.

- Data quality, validation and profiling of large multi-source datasets
- Statistical analysis, hypothesis testing and predictive modelling
- Dashboards and reporting for non-technical audiences
- Database design, stored procedures and audit logging in SQL Server
